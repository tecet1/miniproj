# WP-Genie 벤치마크: 채점기와 질문 틀

## 목표
Genie 답변을 독립 기대값으로 채점하는 도구와 질문 세트의 틀을 만들고, 덤프 재설계가 끝난 뒤 기대값을 채운다.

## 입력 / 산출물
- 입력: `plans/08_Genie_에이전트.md` 카드 8-A·8-D, `expected.py`, (후반) 새 `expected_dump.json`
- 산출물: `03_serving/genie/benchmark/score_answers.py`, 질문 스키마와 `build_questions.py` 틀, 테스트(`02_pipeline/tests/genie/`)

## 단계
1. **지금 시작 가능(덤프와 무관):** 채점기(`score_answers.py`)와 질문 스키마. 채점 규칙은 정수는 정확히 일치, 비율은 질문별 `precision`으로 반올림해 비교, 허용 오차 없음, "없다고 답함" 수동 판정 칸, `MEASURE(` 사용 여부 확인이다. 합성 답변으로 채점기를 테스트한다.
2. **덤프 재설계 이후:** `build_questions.py`로 약 25개 질문의 기대값을 `expected.py`와 새 `expected_dump.json`에서만 계산한다(Gold·Metric View 조회 결과는 쓰지 않는다). 질문은 절대 기간만 쓴다.

## 완료 조건
- 1단계: 채점기가 일치·불일치·비율 반올림·없다고 답함·`MEASURE(` 누락을 구분해 `scores.json`에 기록한다. 채점 로직을 일부러 틀려 테스트가 잡는지 확인한다.
- 2단계: 질문 유형(가산 4, 비가산 5, 귀속 4, 기간 4, 차원 5, 범위 밖 지표 3)과 기대값이 독립 계산과 일치한다.

## 소유 경로
`03_serving/genie/benchmark/`, `02_pipeline/tests/genie/`. Genie 구성 파일(8-B), 접근 통제(8-C), 대시보드는 수정하지 않는다.

## 범위 밖
Genie API 자동화는 미검증이며 사용자 실행이 필요하다. 채널별 행 필터(8-G)는 승인 전 구현하지 않는다. 목표 일치율은 기준선 측정 뒤 사용자가 정한다.

## 상태
상태: 미착수 / 갱신: 2026-10-15 / 지금: - / 다음: 1단계 채점기와 질문 스키마 변경안 제안 / 막힘: 없음 (1단계 시작 가능, 2단계는 WP-덤프 완료 대기)

## 공통 규칙 (모든 WP)

- 먼저 `AGENTS.md`, `plans/결정_로그.md`, `plans/09_병렬_작업_분배.md`를 읽는다. 충돌 시 우선순위는 최신 사용자 지시 > AGENTS.md > plans/ > 이 파일이다.
- **소유 경로 밖은 수정하지 않는다.** 밖의 변경이 필요하면 멈추고 보고한다. 다른 WP가 소유한 파일을 고치지 않는다.
- 변경안(파일, 기대값, 영향, 시간)을 먼저 제안하고 승인 전에는 수정하지 않는다.
- 독립 기대값(`expected*`, 픽스처)을 구현·테스트 통과를 위해 고치지 않는다. 테스트를 삭제·완화하지 않는다.
- 새 테스트는 코드를 일부러 망가뜨려 실패하는지까지 확인한다.
- 로컬 테스트 통과는 Databricks 성공이 아니다. 원격 확인 전에는 '미검증'으로 적는다.
- 전체 테스트에서 `regenerated_fixtures_are_identical`(채널 A·B·C) 3건은 이미 실패 중이다(CRLF 픽스처와 LF 재생성 비교). 이 WP의 변경으로 늘어난 실패와 구분해 보고하고, 이 3건은 고치지 않는다.
- 결정이 생기면 `plans/결정_로그.md` 맨 아래에 한 줄을 추가한다(기존 행은 고치지 않는다).
- UTF-8, 기존 CRLF 유지, BOM 없음. 비밀 값은 넣지 않는다.
- 작업 보고는 목표 / 입력·산출물 / 완료 조건 / 검증 방법 / 상태(완료·미검증·보류)로 쓴다. 확인한 범위와 못 한 범위를 구분한다.
- 작업이 한 단계 끝날 때마다 이 파일의 `## 상태` 절을 갱신한다. 형식은 한 줄이다: `상태: 진행중|완료|미검증|보류 / 갱신: YYYY-MM-DD HH:MM / 지금: <한 줄> / 다음: <한 줄> / 막힘: <없음|내용>`. 집계 명령이 이 절만 읽으므로 다른 내용을 섞지 않는다.
