# WP-Gold: 증분 재계산

## 목표
Silver 변경분에서 이번에 바뀐 주문만 다시 계산해 Gold(`fact_sales_item`, `fact_refund`)에 MERGE한다.

## 입력 / 산출물
- 입력: `plans/07_오케스트레이션과_품질_규칙.md` 카드 7-E, `plans/04_Gold_적재.md`, 현재 `02_pipeline/gold/`(Silver 전체 재계산 후 MERGE)
- 산출물: `02_pipeline/gold/` 증분 로직, 테스트

## 완료 조건
- 증분 결과가 전체 재계산과 같다. 픽스처 `expected.json` 일치는 필수이고, 덤프 기대값 일치는 **병합 시점 main의 `expected_dump.json` 기준**으로 다시 돌린다.
- 이벤트가 순서와 무관하게 늦게 도착해도 같은 결과로 수렴한다(결제가 주문보다 먼저 오는 경우, 환불이 결제보다 늦게 처리되는 경우 포함).
- 같은 변경분을 한 번 더 처리해도 건수와 금액이 같다(멱등).
- PK 중복 0, FK 누락 0, 결제금액 = 상품 합 + 배송비가 유지된다.

## 검증 방법
- `python -m unittest discover -s .\02_pipeline\tests\gold -v`
- 도착 순서를 섞은 입력에서 전체 재계산 결과와 비교하는 테스트. 증분 로직 하나를 일부러 틀려 실패하는지 확인한다.
- Databricks 실행은 사용자 확인 전까지 '미검증'이다.

## 소유 경로
`02_pipeline/gold/`, `02_pipeline/tests/gold/`. `silver/`, `quality/`, `bronze/`, `03_serving/`, `04_experiments/`는 수정하지 않는다. Silver 테이블의 컬럼이 필요하면 멈추고 보고한다.

## 상태
상태: 미검증 / 갱신: 2026-10-15 14:30 / 지금: 명세 변경 7가지 구현 완료(로컬): Silver items ID 중복 격리·order_items 중복 제거, Gold 위반 주문·무효 환불 제외와 보고, 적재 전 PK 중복 검사, payment_hour. 전체 테스트 511건 통과(skipped 21), 변이 17종 확인. Databricks는 미검증 / 다음: 사용자가 run_silver·run_gold·run_metric_views 재실행 / 막힘: 없음

## 공통 규칙 (모든 WP)

- 먼저 `AGENTS.md`, `plans/결정_로그.md`, `plans/09_병렬_작업_분배.md`를 읽는다. 충돌 시 우선순위는 최신 사용자 지시 > AGENTS.md > plans/ > 이 파일이다.
- **소유 경로 밖은 수정하지 않는다.** 밖의 변경이 필요하면 멈추고 보고한다. 다른 WP가 소유한 파일을 고치지 않는다.
- 변경안(파일, 기대값, 영향, 시간)을 먼저 제안하고 승인 전에는 수정하지 않는다.
- 독립 기대값(`expected*`, 픽스처)을 구현·테스트 통과를 위해 고치지 않는다. 테스트를 삭제·완화하지 않는다.
- 새 테스트는 코드를 일부러 망가뜨려 실패하는지까지 확인한다.
- 로컬 테스트 통과는 Databricks 성공이 아니다. 원격 확인 전에는 '미검증'으로 적는다.
- 전체 테스트에서 `regenerated_fixtures_are_identical`(채널 A·B·C) 3건은 이미 실패 중이다(CRLF 픽스처와 LF 재생성 비교). 이 WP의 변경으로 늘어난 실패와 구분해 보고하고, 이 3건은 고치지 않는다.
- 결정이 생기면 `plans/결정_로그.md` 맨 아래에 한 줄을 추가한다(기존 행은 고치지 않는다).
- UTF-8, 기존 CRLF 유지, BOM 없음. 비밀 값은 넣지 않는다.
- 작업 보고는 목표 / 입력·산출물 / 완료 조건 / 검증 방법 / 상태(완료·미검증·보류)로 쓴다. 확인한 범위와 못 한 범위를 구분한다.
- 작업이 한 단계 끝날 때마다 이 파일의 `## 상태` 절을 갱신한다. 형식은 한 줄이다: `상태: 진행중|완료|미검증|보류 / 갱신: YYYY-MM-DD HH:MM / 지금: <한 줄> / 다음: <한 줄> / 막힘: <없음|내용>`. 집계 명령이 이 절만 읽으므로 다른 내용을 섞지 않는다.
